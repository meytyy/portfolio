# Meytyy Portfolio

Персональный сайт-портфолио на React + TypeScript + Vite + Tailwind.
Ссылка: https://portfolio-3gxd1f4pl-meytyys-projects.vercel.app/
Контактная форма отправляет сообщения через FormSubmit. После первой тестовой
отправки нужно один раз подтвердить адрес получателя по письму от FormSubmit.
